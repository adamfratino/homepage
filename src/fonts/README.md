# Fonts

`noto-sans-symbols-2-stars.woff2` is a three-glyph subset (★ U+2605, ☆ U+2606, ⯪ U+2BEA) of Noto Sans Symbols 2 v25 as served by Google Fonts, produced with `subset-font`. It exists because macOS, iOS, and Android ship no glyph for the Unicode half star, so ratings would render as tofu without it.
